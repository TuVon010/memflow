# MemFlow 开发环境搭建指南

本文档帮助开发者在本地搭建 MemFlow 项目的完整开发环境，涵盖必需软件安装、项目获取、依赖安装、运行配置以及常见问题处理。

---

## 1. 软件清单

### 1.1 核心运行时
| 软件 | 版本要求 | 用途 | 安装指引 |
|------|---------|------|---------|
| **Flutter SDK** | 3.24.0+ (stable) | 跨平台移动端框架 | [flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install) |
| **Dart SDK** | 包含在 Flutter SDK 中 | 编程语言 | 同上 |
| **Android Studio** | 2024.1+ (或最新稳定版) | Android SDK 管理、模拟器、IDE | [developer.android.com/studio](https://developer.android.com/studio) |
| **Xcode** | 15.2+ (需 macOS) | iOS 开发与模拟器 | Mac App Store 安装，需安装 Command Line Tools |
| **Git** | 2.40+ | 代码版本管理 | [git-scm.com](https://git-scm.com) |

### 1.2 推荐 IDE 与插件
建议使用 **VS Code**（轻量高效）或 Android Studio / IntelliJ IDEA。

**VS Code 插件：**
- **Flutter** (官方)
- **Dart** (官方)
- **Flutter Widget Snippets** (快速生成代码片段)
- **Prettier** – 代码格式化（支持 Dart 配置文件）
- **GitLens** – 增强 Git 功能

### 1.3 可选工具
- **Docker Desktop**：如需本地测试 LLM (运行 Ollama 容器)，非必需。
- **Postman / Bruno**：调试 AI API 请求，非必需。

## 2. 项目克隆与依赖安装

### 2.1 获取代码
```bash
git clone https://github.com/your-org/memflow.git
cd memflow
```

### 2.2 安装 Flutter 依赖
```bash
flutter pub get
```

### 2.3 生成 Isar 模型代码
MemFlow 使用 Isar 数据库，模型定义使用注解，需通过 `build_runner` 生成适配代码。
```bash
dart run build_runner build --delete-conflicting-outputs
```
**说明**：若修改了 `lib/data/models/` 下的模型文件（如添加字段），需重新执行此命令。

## 3. 运行配置

### 3.1 Android 运行

#### 模拟器
1. 打开 Android Studio → **Virtual Device Manager** → 创建虚拟设备（推荐 Pixel 系列，API 34+）。
2. 启动模拟器。
3. 在项目根目录执行：
   ```bash
   flutter run
   ```
4. 首次运行会下载 Gradle 依赖，等待完成即可。

#### 真机调试
1. 手机开启 **开发者选项** → 打开 **USB 调试**。
2. USB 连接电脑，在手机上授权调试。
3. 执行 `flutter devices` 确认设备已识别。
4. 运行 `flutter run`。

**注意**：Android 端无需额外签名配置即可调试运行，但要安装 release APK 需配置签名（见发布文档）。

### 3.2 iOS 运行（仅限 macOS）

#### 模拟器
1. 确保 Xcode 已安装，并至少添加一个 iOS 模拟器（Xcode → Settings → Platforms）。
2. 打开模拟器（`open -a Simulator` 或从 Xcode 启动）。
3. 执行 `flutter run`。

#### 真机调试
1. 打开 Xcode，登录 Apple ID（Preferences → Accounts）。
2. 连接 iPhone，在项目目录下打开 `ios/Runner.xcworkspace`（注意不是 `.xcodeproj`）。
3. 选择你的设备，点击运行。
4. 首次运行可能需要在 iPhone 上信任证书：**设置 → 通用 → VPN 与设备管理 → 信任开发者**。

**注意**：iOS 免费开发者账号每 7 天签名过期，需重新构建运行。付费账号无此限制。

### 3.3 指定目标设备
```bash
# 查看已连接设备
flutter devices

# 指定设备运行（例如 iPhone 15 模拟器）
flutter run -d iPhone-15
```

## 4. 环境变量与配置

本应用**无后端服务**，所有配置项位于 App 内部设置中（通过 `UserSettings` 模型持久化）。开发阶段不需要配置任何环境变量。

但以下内容可在开发时预先填充以方便测试：

### 4.1 AI 端点预设（非必需）
在 `lib/core/constants.dart` 中提供了默认的 LLM 预设（用户仍可在设置界面修改）：

```dart
const Map<String, LLMPreset> llmPresets = {
  'openai': LLMPreset(
    name: 'OpenAI',
    baseUrl: 'https://api.openai.com/v1',
    defaultModel: 'gpt-4o',
  ),
  'deepseek': LLMPreset(
    name: 'DeepSeek',
    baseUrl: 'https://api.deepseek.com/v1',
    defaultModel: 'deepseek-chat',
  ),
  'ollama': LLMPreset(
    name: 'Ollama',
    baseUrl: 'http://localhost:11434/v1',
    defaultModel: 'llama3',
  ),
};
```
开发者可以直接使用这些预设，测试 AI 功能时需要在 App 内填入有效 API Key。

### 4.2 本地数据库路径
Isar 数据库默认存储在应用沙盒目录，路径由 `path_provider` 获取。无需手动配置。若需查看或调试数据库文件，可使用 Isar Inspector 或导出 JSON。

## 5. 常见问题

### Q1: `flutter pub get` 报网络错误
- 切换至国内镜像：设置环境变量 `PUB_HOSTED_URL=https://pub.flutter-io.cn` 和 `FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn`（临时方案，或使用 VPN）。

### Q2: Android 模拟器无法启动
- 确保已在 BIOS 中开启虚拟化技术（Intel VT-x / AMD-V）。
- 检查 Android SDK 是否完整安装（Android Studio → SDK Manager）。

### Q3: iOS 模拟器卡在启动页面
- 执行 `flutter clean` 后重新 `flutter run`。
- 删除 `ios/Pods` 文件夹，重新执行 `cd ios && pod install`。

### Q4: `build_runner` 生成失败
- 确认所有模型文件无语法错误。
- 执行 `flutter clean && flutter pub get` 后重试。

### Q5: 真机运行时提示“不受信任的开发者”
- iOS：前往 **设置 → 通用 → VPN 与设备管理** 信任证书。
- Android：允许安装未知来源应用（部分系统会提示）。
