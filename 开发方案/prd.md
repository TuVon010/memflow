# MemFlow（记忆流）PRD v1.0

**产品名称**：MemFlow（记忆流）  
**产品类型**：纯移动端离线 AI 记忆卡应用  
**目标平台**：iOS 15+ / Android 10+  
**开发框架**：Flutter  
**文档版本**：1.0  
**日期**：2026-07-25  

---

## 1. 产品概述

### 1.1 产品定位
一款面向程序员群体的**离线优先、AI 增强的间隔重复记忆工具**，专注于帮助用户高效记忆技术面试八股文（Java、计算机网络、操作系统等）。通过大模型自动将笔记/文档拆解为高质量问答卡片，结合改良的 SM-2 算法与复习时划词 AI 答疑，将“背八股”从低效的反复阅读转变为科学的主动回忆。

### 1.2 核心价值
- **AI 自动制卡**：粘贴一段八股文本，AI 在本地辅助下（调用用户自带 API Key）拆解为一张张问答卡片，省去手动整理的繁琐。
- **科学记忆引擎**：基于改良 SM-2 算法的间隔重复，自动安排复习时间，确保在遗忘临界点前巩固记忆。
- **沉浸式复习**：支持划词 AI 追问、面试倒计时模式、代码高亮与挖空，贴合技术人员的使用习惯。
- **数据完全私有**：所有卡片与学习记录仅存储在用户手机本地，无需注册账号，无需联网（除 AI 调用外）。AI 调用可选、可控，API Key 由用户自己提供，成本完全透明。

### 1.3 目标用户
- **主要用户**：正在准备技术面试的初中级程序员，需要系统记忆 Java、并发、JVM、Spring、MySQL 等八股文。
- **次要用户**：其他领域的知识工作者（如学生、语言学习者），但 MVP 阶段界面与交互侧重代码技术场景。

## 2. 功能需求

### 2.1 功能总览
| 模块 | 核心功能 | 优先级 |
|------|---------|--------|
| 卡组管理 | 创建/编辑/删除卡组，手动添加单张卡片 | P0 |
| AI 智能制卡 | 粘贴文本，调用 LLM 拆解为多张问答卡片 | P0 |
| 卡片编辑 | 批量修改、删除、移动卡片，支持 Markdown / 代码高亮 | P0 |
| 间隔重复复习 | 基于 SM-2 改良算法的每日复习队列，评分（生疏/犹豫/顺畅） | P0 |
| 划词 AI 答疑 | 复习答案时选中任意文字，即时向大模型追问原理 | P0 |
| 面试倒计时计划 | 设置面试日期，动态调整每日新卡与复习量，确保重点覆盖 | P1 |
| 本地提醒 | 自定义每日复习时间，本地通知推送 | P1 |
| 数据导入/导出 | 支持 JSON / CSV 格式的卡组导出与导入，用于备份和手动分享 | P1 |
| 学习统计 | 每日复习量、记忆留存率曲线、连续打卡天数 | P2 |
| 代码沙盒 | 卡片内的代码块可直接编辑并运行（Dart 实现简单解释器） | P3（远期） |
| 语音复习 | 通勤时通过语音交互完成复习（语音输入评分） | P3（远期） |

### 2.2 功能详细描述

#### 2.2.1 卡组与卡片管理
- **创建卡组**：输入名称与描述，创建一个空卡组。
- **添加卡片**：在卡组内点击“添加卡片”，进入编辑界面。问题与答案区域均支持 Markdown 语法与代码高亮。可选卡片类型：基本（一问一答）、代码填空（答案中 `___` 处留空）、对比（自动分左右两栏）。
- **AI 拆卡**：在卡组内提供“AI 生成”入口。粘贴一段技术文本（如面经、文档段落），点击生成。App 将调用 LLM API 解析为 3~5 张卡片预览，用户可逐张编辑、删除或直接确认添加。**此功能要求用户已在设置中填入有效 LLM API Key（OpenAI / DeepSeek 等）**。
- **批量操作**：支持多选卡片后移动至其他卡组或批量删除。
- **卡片导入/导出**：单个卡组可导出为 `.mfcard.json` 文件，可通过文件或分享方式导入其他设备。

#### 2.2.2 复习引擎（核心）
- **复习队列生成**：每日凌晨，系统根据 `ReviewState` 中 `due <= 当前时间` 的卡片生成当天的复习队列。新卡按照创建顺序或用户设定的优先级（如面试倒计时权重）加入，并受“每日新卡上限”约束（默认 20 张，可修改）。
- **评分机制**：复习时，先显示问题区域，用户可点击“显示答案”或倒计时自动显示。答案区域支持代码高亮。底部提供 3 个评分按钮：
  - **生疏**：完全忘记，间隔重置为 1 天，EF 降低。
  - **犹豫**：回忆困难但看到答案后能想起，间隔按当前 EF 缩短。
  - **顺畅**：轻松回忆，间隔按 EF 增长。
- **SM-2 改良算法**：
  - 初始 EF = 2.5，初始间隔 1 天。
  - 评分量化：生疏=0，犹豫=3，顺畅=5。
  - EF' = EF + (0.1 - (5-q) * (0.08 + (5-q)*0.02))
  - 间隔计算：如果评分 ≥ 3，则 interval = interval * EF'；如果 = 0，则 interval = 1。
  - 引入“成熟度”概念，防止新卡过早出现极大间隔。
- **复习界面交互**：
  - 卡片支持 Markdown 渲染，代码块支持语法高亮（使用 `highlight` 包）。
  - 答案区文字可**长按选中**，弹出上下文菜单“问 AI”，点击后弹出底部抽屉，展示 AI 对选中内容的解释。
  - 解释结果底部有“生成追问卡片”按钮，可将该问答对保存为一张独立卡片，并自动关联到当前卡组。

#### 2.2.3 面试倒计时计划（P1）
- 用户设置面试日期和每日可投入学习时长。
- 系统根据所有待复习卡片的总量、优先级（高频题目标）和剩余天数，动态计算每日最少新卡与复习量。
- 在复习主页顶部显示“距离面试 X 天”进度条，以及预计完成百分比。
- 开启此模式后，高权重卡片会被提前调度，且在复习时被标注“高频”标记。

#### 2.2.4 AI 配置与调用
- 用户在“设置”中填入 LLM 服务商的 API Base URL 和 API Key，以及首选模型名称。
- App 提供预设模板：OpenAI、DeepSeek、Ollama（本地地址），支持自定义。
- 所有 AI 调用直接由 App 发起，不经过任何第三方服务器。请求失败时重试 2 次，并给出友好提示。

#### 2.2.5 数据统计（P2）
- 复习主页展示：今日复习量、连续打卡天数、当前记忆留存率（基于近期评分估算）。
- “统计”Tab 显示：过去 7/30 天每日复习量柱状图，遗忘曲线，各卡组掌握率饼图。

#### 2.2.6 提醒与通知
- 用户可设置 1~3 个每日固定复习提醒时间。
- 使用 `flutter_local_notifications` 实现本地通知，无需联网。

## 3. 用户故事与流程

### 3.1 首次使用引导
1. 用户启动 App，进入欢迎页，简要介绍核心功能（本地存储、AI 制卡、间隔重复）。
2. 引导用户创建一个第一个卡组“示例卡组”。
3. 进入“设置”引导用户填写 AI API Key（可跳过）。
4. 进入示例卡组，引导粘贴一段文本并生成 3 张卡片，或直接演示手动添加一张卡片。
5. 完成引导，返回复习主页。

### 3.2 典型学习场景
**场景一：日常复习**
- 打开 App → 首页显示“今日待复习 56 张” → 点击“开始复习” → 看到问题 → 脑中回忆 → 点击显示答案 → 长按选中不理解的点 → 点击“问 AI” → 阅读解释 → 关闭弹窗 → 点击“顺畅” → 进入下一张 → … → 完成复习，显示庆祝动画和本次统计数据。

**场景二：临时制卡**
- 看到一篇高质量 Java 并发面经 → 复制全文 → 打开 App → 进入指定卡组 → 点击“AI 生成” → 粘贴文本 → 确认调用 → 等待 3 秒 → 预览 4 张卡片 → 删除一张不满意的，编辑另一张的答案 → 点击“全部添加” → 完成。

**场景三：面试冲刺**
- 设置 15 天后面试 → 开启面试倒计时 → 每日复习首页提示“高频未掌握卡片 12 张” → 复习时该卡片右上角显示红色“高频”标签 → 系统自动增加这类卡片的出现频率。

## 4. 非功能需求

### 4.1 性能
- 复习页面滑动切换卡片延迟 < 16ms。
- AI 调用超时时间 30s，超时提示用户。
- 本地数据库查询 1000 张卡片耗时 < 200ms。

### 4.2 离线可用
- 除 AI 调用外所有功能完全离线可用（创建卡片、复习、统计）。
- 无网络时不展示任何错误提示，AI 入口显示“当前无网络”状态。

### 4.3 安全性
- 用户的 API Key 使用 `flutter_secure_storage` 加密存储。
- 所有本地数据使用 Isar 数据库，文件不包含在 iCloud/Google Drive 自动备份中（避免隐私泄露）。

### 4.4 兼容性
- 支持从 Android 10 到最新版本，iOS 15 以上。
- 支持小屏手机（4.7 英寸）的界面自适应。

## 5. 界面与交互原则
- **极简**：复习界面去除非必要元素，沉浸式卡片展示。
- **暗黑模式**：默认提供浅色/深色主题，代码区域始终使用深色背景。
- **手势友好**：复习时可通过左右滑动切换评分快捷手势（左滑生疏，右滑顺畅，上滑犹豫）作为评分按钮的辅助。
- **触觉反馈**：评分后轻微震动。

## 6. 版本规划
- **v0.5 (内部测试)**：手动卡组创建、基本复习、SM-2 算法、本地存储、无 AI。
- **v0.8 (Alpha)**：集成 AI 制卡、划词答疑、面试倒计时、数据导入导出。
- **v1.0 (MVP 正式发布)**：完善 UI、引导流程、统计图表、本地通知，上架应用商店。
- **v1.5+**：代码沙盒、语音复习、社区卡组分享（通过 JSON 文件离线交换）。

## 8. 风险与应对
- **AI 依赖风险**：用户可能不愿意自备 API Key。应对：提供本地免费小模型选项（Ollama），或后续提供官方 Token 充值服务。
- **算法质疑**：SM-2 可能不适应代码类记忆。应对：开放调度算法插件化设计，允许社区贡献新算法。
- **竞品压力**：应对：依靠开源与社区驱动内容生态，形成差异化壁垒。
