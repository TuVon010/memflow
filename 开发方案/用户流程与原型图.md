# MemFlow 用户流程与交互原型

## 一、整体信息架构

```
App 入口
├── 复习 Tab（首页）
│   ├── 今日复习概览
│   ├── 开始复习 → 卡片复习页
│   └── 复习完成页
├── 卡组 Tab
│   ├── 卡组列表
│   ├── 卡组详情 → 卡片列表
│   ├── 创建/编辑卡片
│   └── AI 生成卡片
├── 统计 Tab
│   ├── 学习日历
│   ├── 记忆留存率
│   └── 各卡组掌握度
└── 设置 Tab
    ├── AI 配置
    ├── 复习偏好
    ├── 面试倒计时
    ├── 提醒时间
    └── 数据导入/导出
```

## 二、核心用户流程

### 2.1 首次使用引导流程


## 四、交互细节说明

| 交互 | 实现方式 | 说明 |
|------|---------|------|
| 卡片翻转 | 点击或上滑 | 3D 翻转动画，或简单缩放替换 |
| 显示答案 | Tap 空白区 | 先显示问题，主动点击才显示答案（主动回忆） |
| 划词问 AI | 长按文字 → 弹出系统菜单 → "问 AI" | 使用 Flutter `SelectableText` + `showBottomSheet` |
| 手势评分 | 左滑=生疏，右滑=顺畅，上滑=犹豫 | 在评分按钮外提供手势快捷方式 |
| 卡片删除 | 复习中遇到不满意的卡片，点击 ⋮ → 编辑/删除 | 不打断复习流 |
| 空状态 | 每个列表都有插图 + 引导文案 | 避免空白页让用户困惑 |
| Loading | AI 调用显示 shimmer（骨架屏）效果 | 减轻等待焦虑 |

## 五、用户情绪曲线与体验打磨

```
开心     ╭─ 完成复习，看到统计
         │
         │  ╭─ 滑动手势顺滑
         │  │
中性 ────┼──┼─────────────
         │  │   ╭ 遇到生疏卡
         │  │   │
         │      │    ╭ 恢复学习
         └──────┴────┴─────
引导  首次复习  连续遗忘   AI答疑解决疑问
```

**关键体验点**：
1. **首次 AI 制卡成功后给予惊喜感**：卡片自动生成，配上 👍 表情动画。
2. **遗忘不惩罚**：生疏评分后不要给出负面反馈，而是说“没关系，这正是复习的意义”。
3. **连续打卡**：第 7/30/100 天打卡有特殊动画，增强成就感。
